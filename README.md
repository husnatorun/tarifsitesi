# BLM2537 Ağ Tabanlı Programlamaya Giriş - Dönem Projesi

Bu depo, BLM2537 Ağ Tabanlı Programlamaya Giriş dersi kapsamında geliştirilen **Yemek Tarifleri ** projesinin kaynak kodlarını ve haftalık ilerleme kayıtlarını içermektedir.

* **Öğrenci Adı Soyadı:** Hüsna Torun
* **Proje Konusu:** Yemek Tarifleri Portalı


---

### Haftalık Geliştirme Özeti

* **Hafta 1:** Proje ana sayfası (`index.html`) iskeleti oluşturuldu, temel tasarım yapısı başlatıldı.
* **Hafta 2:** `menulerimiz.html` sayfası geliştirildi. HTML5 semantik etiketleri (`<main>`, `<section>`, `<ul>`, `<ol>`), yemek listesi tablosu (`colspan` kullanımı) ve harici stil dosyası (`stil.css` ile kutu modeli ve ortalama) projeye dahil edildi.
